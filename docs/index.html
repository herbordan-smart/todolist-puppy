住在桌面角落的任务小狗

一只常驻桌面右下角的小狗，用表情告诉你今天的任务进展。桌面宠物端负责「此刻」，网页端报告负责「回顾」。

体验桌面宠物端 体验网页端报告 查看源码

小狗的 4 种状态

状态由任务数据自动判定，按优先级只呈现一种。

工作中

进行中任务 > 0

有任务正在进行，陪你一起专注。

准备出发

待办任务 > 0

清单里还有事，轻轻催你开始。

开心玩耍

今日有完成 且 无待办

今天的任务清零，这是给你的奖励。

安静等待

以上都不满足

还没有任务，摸摸小狗添加第一条吧。

两个端，一份数据

在任一端修改任务，另一端即时同步。

安装到你的 Mac

真正的桌面宠物是 Electron 应用，需要 macOS 与 Node.js 18+。

git clone https://github.com/herbordan-smart/todolist-puppy.git
cd todolist-puppy
npm install
npx electron .

本页的在线演示是浏览器模拟：界面与交互复用真实代码，数据只保存在你当前浏览器的 localStorage 中（示例数据每天自动重置），不会上传。
